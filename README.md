# ADVENTURE-WORKS-DASHBOARD
I sourced the dataset from Kaggle and began by reviewing and understanding the data, including the different tables, fields, and how the data was structured, before importing it into Power BI for modelling. I identified the main data tables and LOOKUP tables and created the appropriate relationships between them, including one-to-many, many-to-many and one-to-one relationships. I created calculated columns, data tables, and DAX (Data Analysis Expressions) measures that can dynamically adjust based on slicer selections, allowing the report to respond to user interactions. I also built hierarchies within the data model to make navigating and analysing different levels of the data easier. After building the model, I validated the relationships and overall structure to ensure the data was properly connected and suitable for analysis. I then applied the changes, reviewed the model and refined it where necessary. DAX functions used in the project include SUM, AVERAGE, COUNT, MIN, MAX, and CONCATENATE, among others. This project demonstrates my practical experience in Power BI data modelling, DAX calculations, data validation, and preparing structured data for interactive analysis. After completing the analysis, I documented the key insights and recommendations derived from the data to highlight important patterns, relationships, and potential areas for decision-making.
